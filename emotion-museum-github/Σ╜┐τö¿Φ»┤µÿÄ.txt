情绪博物馆｜React + Tailwind 移动端 App 原型

运行环境：Node.js 20.19+（或 22.12+）

启动：
1. 在此文件夹打开终端。
2. 首次运行执行：npm install
3. 执行：npm run dev
4. 打开终端显示的本地地址。桌面端可用左侧页面导航，手机端可点页面按钮或左右滑动。

构建：npm run build
构建产物在 dist/ 文件夹。

说明：
- 11 个页面均以内嵌原始分层 SVG 作为视觉底稿，保持设计稿画面和排版；交互热区与 390×844 画布坐标对齐。
- 心情选择、记录输入、日历日期、展厅卡片、释放方式、聊天输入和隐私开关均可交互。
- 记录和隐私设置保存在浏览器本机；聊天为本地演示回复，没有接入线上 AI。
- 原始 SVG 在 pages/ 文件夹中，可单独继续编辑或导入 Figma。
